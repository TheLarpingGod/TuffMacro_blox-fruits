#THIS PROJECT IS DEPRECATED AND WILL NEVER RECEIVE ANY UPDATES
### 1. Makes all moves to be PERFECTLY timed in combo with any ping
no matter of your ping this macro will always do the fastest version of your combo without skiping any moves.
### 2. Literaly a legal *AutoAim* (not bannable)
works only with observation haki enabled (still broken tho).
### 3. Smart AutoCombo
macro will automaticaly start a combo after certain key is pressed and certain slot is active (higtly configurable),
###### ex: automatically start a combo after gh C only if `held variation was used and you didnt miss`.
### 3.1 Auto slot detection
automaticaly detects which slot is currently active.
### 4. Easy to configure
you can change setting such as:
  - your build (so macro will know what combos to use)
  - slot positions (if you prefer putting your gun in the 3th slot)
  - and more

<a name="install"><h1>HOW TO INSTALL</h1></a>
1. Dowload ahk **v2.0** from the [Official AutoHotkey Website](https://www.autohotkey.com) if you havent already
2. Downlaod the latest realease
3. Extract it to a new folder
4. Run `Main.ahk`

<a name="usage"><h2>How to use</h2></a>
- After you ran `Main.ahk` the `config.ini` file will appear in the macro's folder. In this file you can change some general settings.
- Currently working keybinds:
  - XButton1 (4th mouse button) or F3 - Reload (usefull to force stop a combo)
  - XButton2 (5th mouse button) - AutoAim + AutoSoru
  - combos are being activated automatically

<a name="minor_features"><h2>Minor Features</h2></a>
#### 1. Auto combo cancelation
if your combo was interupted then macro will automaticaly cancel your combo so it wont just spam random moves if you got stunned during combo. (can be disabled)
#### 2 Supports any keyboard languages/layouts
every combos will work even if your active keyboard layout isn't english (most .ahk macros actually dont support this)
