<a name="features"><h2>Features</h2></a>
### 1. Makes all moves to be PERFECTLY timed in combo with any ping
no matter of your ping this macro will always do the fastest version of your combo without skiping any moves.
### 2. Literaly a legal *AutoAim* (not bannable)
works only with observation haki enabled (still broken tho).
### 3. Smart AutoCombo
macro will automaticaly start a combo after certain key is pressed and certain slot is active (higtly configurable), ex: automatically start a combo after gh C only if `held variation was used and you didnt miss`.
### 3.1 Auto slot detection
automaticaly detects which slot is currently active.
### 4 Easy to configure
after macro was launched for the first time, the `config.ini` file will appear in macro folder where you can configure such things as:
1. your build (so macro will know what combos to use)
2. slot positions (if you prefer putting your gun in the 3th slot)
3. shuld low ping techs be used during combos (like gh C to gh Z)

<a name="minor_features"><h2>Minor Features</h2></a>
#### 1. Auto combo cancelation
if your combo was interupted then macro will automaticaly cancel your combo so it wont just spam random moves if you got stunned during combo. (can be disabled)
#### 2 Supports any keyboard languages/layaouts
every combos will work even if your active keyboard layaout isnt english (most .ahk macros actually dont support this)
